# 鱼鱼的耳朵（dsh-hear）

给 DSH 里跑着的 agent 装一对耳朵：**整段波形直接交给会听音频的模型**，让它听后描述听感，插件再自己算基频、能量、频谱重心和停顿，两边对得上才算数。

不是把声音转成文字再读——那不算听。

| 路径 | 是什么 |

## 现在能做什么（v0.1.0）

- 听一段音频，回四块：结论 / 补充 / 情绪时间点 / 自己算的数值；
- 超过一分钟先问要不要分段，点头才按 30 秒切开听；
- 盯 QQ 桥接落盘的语音：连续发以最后一条之后静默 9 秒为准，听完进上下文，也可以主动回一条；
- 模型页能下载、体检、切换、卸载八个模型；云端（Gemini / GPT-4o / 通义）填 Key 即用；
- 诊断页 12 项检查 + 一键修复；
- 显示不足、端口被占、僵尸进程、清理提醒这些都有提示。

## 现在还不能

- 只有 Qwen2-Audio-7B 的推理是真跑通的；Qwen2.5-Omni、MiniCPM-o 的代码写了但没实测；GLM-4-Voice、Step-Audio-2-mini、Kimi-Audio 只能下载；
- 7B 4bit 偶尔会把咬字的咔哒声说成「掌声」，细情绪（平静 / 悲伤）会判错；
- 详情看 [dsh-hear/README.md](dsh-hear/README.md) 的「已知问题」。
